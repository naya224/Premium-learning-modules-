# Premium Learning Modules

## Project Overview
An Android application developed using Kotlin and Android Studio to provide premium learning content through in-app purchases.

## Features
- Google Play Billing integration
- Monthly and yearly subscription plans
- Premium learning module access
- Payment logs and receipt generation

## Technology Stack
- Kotlin
- Android Studio
- Google Play Billing API

## Project Purpose
This project aims to provide a seamless and professional in-app payment experience for premium learning services.
